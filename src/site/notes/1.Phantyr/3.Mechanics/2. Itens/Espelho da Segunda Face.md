# Propriedades
- Uma vez por dia, permite observar o reflexo de uma criatura que o usuário conheça pelo nome, desde que ela esteja no mesmo plano.
- A imagem dura até 1 minuto.
- A criatura observada não percebe que está sendo espionada.
- Se o espelho for utilizado durante a noite, existe uma pequena chance de mostrar algo que não deveria estar ali...
